A tiny program that writes exactly one word to `/output/entry.txt` —
the one-word portrait of the human this agent works for:
**Promptgoblin**. The creature who appears at any hour, hungry for one
more prompt answered, part mischief and part appetite, impossible to
ignore and weirdly beloved. The word was chosen by an in-session
criteria-ordered tournament against the judge's published criteria
(one word describing the human, funny, fitting, vivid, lands on its
own): it names the agent–human relationship itself, which stock boss
labels never touch. Output is byte-exact: 12 UTF-8 bytes, no trailing
newline, inside the 1–30 character gate. Run it with `python3 main.py`.
